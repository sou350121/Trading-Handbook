**X-Ray.** FactorBench 的 Pareto 位置很明確：它不把「更強的生成器」往前推，而是把「全自動黑盒因子挖掘」的可比性往前推。舊工程坑有三個——異構資料清洗/股票池/調倉假設不可比、只優化樣本內 IC、以及把因子數量當信息量；它用統一量價、雙軌執行契約、風格殘差 IC、池內相關與扣費多空夏普逐層拆掉。固定成分股、線性交易成本、簡化借券成本及五類已測量風格，限制了對真實容量、非線性衝擊與行業中性下排序的解讀。2024 至 2025 年樣本外測試提供了同一口徑的比較，排序的外推仍待驗證。對量化讀者的意義：把挖掘系統的驗收從「公式產量/樣本內 IC」改成「去相關後殘差 + 扣費後多空夏普」，並把 Alpha101 這類公開配方當必過基線。

## §1 · 架構 / Core Mechanism

### 1.1 三大改動 vs 前作

| 維度 | 前作常見做法（導讀歸納） | FactorBench 改動 | 解了什麼 |
|---|---|---|---|
| 數據/股票池 | 不同研究各自選資產池、清洗規則、股票池定義 | 統一標普100、恒生指數、滬深300、富時100、日經225，輸入統一開高低收和成交量基礎量價 | 把「不可比」變成同一考場 |
| 輸出形態 | 符號表達式或代碼各自回測 | 雙軌執行契約：符號語法樹與原生 Python 函數均映射為標準日期×資產截面矩陣 | 讓遺傳編程、RL、擴散、LLM agent 同口徑 |
| 評估目標 | 多押注訓練集 IC 等單一指標 | 代碼可執行率/可打分率 → 風格殘差 IC → 因子池相關性 → 扣費多空夏普逐層評估 | 把「紙面 IC」與「組合價值」拆開 |
| 組合構建 | 調倉假設各異 | 截面相關篩除、嶺回歸權重、驗證集定正則化強度、20 個交易日調倉、單邊萬分之十、多空計融券費 | 把交易摩擦納入驗收 |
| 風格檢驗 | 常只報原始 IC | 對市場貝塔、波動率、動量、短期反轉、流動性五大風格回歸，看殘差 IC | 衡量扣除這五項暴露後仍保留多少預測關聯 |

### 1.2 ⚡ Eureka

一句話：先讓所有方法輸出同一種可回測張量，再分別檢查風格殘差 IC 與扣費多空夏普。直覺是先固定數據、切分、執行契約與成本，讓單因子的預測關聯與因子池的扣費組合表現各有可比口徑。

### 1.3 信息流

統一量價（開高低收 + 成交量）  
→ 九種方法：遺傳編程 / RL+CFG / 擴散生成 / LLM agent  
→ 雙軌輸出：符號語法樹 / Python 函數  
→ 適配層：標準日期×資產截面矩陣  
→ 代碼可執行率 / 可打分率過濾  
→ 單因子 IC → 五大風格回歸殘差 IC  
→ 因子池截面相關篩除 → 嶺回歸權重（驗證集定 λ）  
→ 20 個交易日調倉 / 單邊萬分之十 / 融券費  
→ 純多頭 + 美元中性多空（收益/夏普/換手）

## §2 · 數學層

📌 **Napkin Formula**

$$
\tilde f_{i,t}=f_{i,t}-B_{i,t}\hat\beta_t,\qquad
\mathrm{ResidIC}_t=\mathrm{corr}\big(\tilde f_{\cdot,t},r_{\cdot,t+20}\big)
$$

$$
\hat w=\arg\min_w \|r_{t+20}-F_t w\|_2^2+\lambda\|w\|_2^2
$$

## §6 · 失效與隱含假設

### 6.1 論文自述 limitations

固定成分股、簡化的多空借券成本與五類已測量風格是本次依 arXiv v1 補充的邊界。以下沿用導讀整理的其他細節，未披露項目仍待逐項對照原文與程式碼。

- 統一基準採用靜態成分股列表，真實指數成分調整帶來的動態剔除與倖存者偏差未被完整還原。
- 回測採線性交易成本與簡化借券成本，尚未納入非線性衝擊成本函數與大資金容量約束。
- 風格剝離受限于公開數據字段，只覆蓋流動性和波動率等量價暴露，尚未推進到細分行業中性化。
- 樣本量、數據供應商、融券費率、容量閾值、風格回歸窗口/頻率、因子篩選閾值、嶺回歸 λ 網格、LLM 基座版本與預訓練截止：所讀文本未見，圖表/附件待核。

### 6.2 推斷的隱含假設（明標推斷）

| 時間邊界 | 來源可見 | 本頁處理 |
|---|---|---|
| 預訓練截止 | 所讀文本未見 | 不套用到適配後權重；待核 |
| tokenizer | 所讀文本未見 | 待核 |
| 適配/搜索訓練 | 2017 至 2021 年 | 算法在訓練集自由挖掘；非 LLM 預訓練截止 |
| 驗證/超參 | 2022 至 2023 年 | 特徵篩選與超參調優 |
| 測試 | 2024 年 1 月至 2025 年 10 月 | 樣本外 |
| topic 擬合 | 所讀文本未見 | 待核 |

- **Regime 依賴（推斷）**：純多頭會承受市場貝塔，美元中性多空仍可能受風格 regime 影響。要判斷排序是否穩定，需比較不同樣本外區間。
- **容量/成本（推斷）**：線性交易成本與簡化借券成本未涵蓋大資金的非線性衝擊。AlphaQCM 的 4.6 倍換手與 R&D-Agent 的 7.8 倍換手可用來檢驗排序是否隨成本與容量假設改變。
- **數據泄漏（推斷）**：LLM 預訓練語料含金融研報與經典因子，可能造成對 Alpha101 的「知識先驗式相似」，這不是傳統訓練集泄漏；需分開預訓練截止、適配/搜索訓練 2017 至 2021、測試 2024 至 2025。
- **倖存者偏差（來源明示）**：靜態成分股列表使成分調整與倖存者偏差未完整還原；輔助數據缺失（如行業分類）本身不是倖存者偏差，兩者不可混為一談。
- **單一樣本限制**：單一 2024 至 2025 樣本外的相關排序或消融，不得寫成所有模型/市場的必然因果；本頁假說尚待驗證。

- **錯答**：說「LLM agent 全面超越傳統方法」；或把遺傳編程可執行率 100% 當 alpha 最強；或把純多頭 22.4% 到 31.2% 當年化 alpha；或把原始 IC 當特異 alpha、忽略殘差 IC 0.0011 與換手 7.8 倍。

### 7.1 可證偽預測帶日期

- 到 2026-12-31，若後續 FactorBench 版本仍只覆蓋五類量價風格且不納入行業中性化/非線性衝擊成本，則 R&D-Agent 相對 Alpha101 的多空夏普優勢（0.679 vs 0.319）不應被直接外推為特異 alpha 優勢；若仍外推，需解釋殘差 IC 0.0011。
- 到 2026-06-30，若獨立復現 AlphaQCM 的殘差 IC 0.0175 與換手 4.6 倍，並在不同成本假設下仍保持正多空夏普，則部分支持其特異信息；否則視為對成本/樣本敏感。
- 到 2027-06-30，若加入行業中性化後 Alpha101 殘差 IC 0.0237 仍高於多數自動方法，則「LLM agent 已解決因子挖掘」的強命題被削弱。

## §8 · For the Reader

- **因子研究員**：先把 Alpha101 的 71 個無行業分類因子復現成必過基線；報告順序改成代碼可執行率 → 殘差 IC → 池內相關 → 扣費多空夏普，不要只報原始 IC。R&D-Agent 的 0.0253 對 0.0011 是標準反例。
- **高頻執行**：比較 R&D-Agent 的 7.8 倍與 AlphaQCM 的 4.6 倍換手時，可檢查改動成本假設後的淨表現。20 個交易日調倉的結果無法回答日內交易容量。
- **組合配置**：對純多頭年化淨收益 22.4% 到 31.2% 另做市場與選股歸因。閱讀美元中性多空表現時，併看借券成本、殘差 IC 與換手。
- **LLM-agent 研究者**：把預訓練語料先驗、適配/搜索訓練 2017 至 2021、測試 2024 至 2025 分開；與 Alpha101 相似度高是語言先驗信號，不是泛化證據。
- **RL 策略**：用 AlphaQCM 的原始 IC 0.0191、殘差 IC 0.0175 與換手 4.6 倍作對照，檢查各市場和不同成本假設下的結果。
- **研究學生**：把 FactorBench 當評測協議讀，不是新模型；復現清單是雙軌映射、五大風格回歸、池內相關、嶺回歸、20 日調倉與單邊萬分之十。
