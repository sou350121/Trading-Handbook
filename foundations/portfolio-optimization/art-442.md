# 微观执行模型 + 部分调整 解構（微观执行模型 + 部分调整）

**TL;DR:** 用 NYSE 逐筆高頻數據逐股逐日估計非線性衝擊成本，把 35 種異象的月度調倉映射成容量曲線。核心 trick 是分離線性半價差與二次方衝擊，並用每月只補目標缺口百分之五的部分調整平滑換手。對五軸的意義是 Alpha 生成從「預測收益」下沉到「組合執行優化」，容量成為中長周期策略的一等約束。來源稱因子中位數容量由十五億美元升至兩百一十億美元（最佳速度；固定百分之五亦稱提升九倍），但樣本內外切分與原論文限制待核。

**X-Ray.** 這篇的貢獻不是新 Alpha，而是把容量做成可計算的執行層約束：同一組信號，因換手與盤口深度不同，可承載資金可差兩個數量級。它解掉舊回測「成本與規模無關」的工程坑，也把部分調整的非對稱性——線性費用按比例降、二次方衝擊按平方降——變成可操作旋鈕。我的判斷：它打不開的 envelope 是更高頻換手場景與非 NYSE 市場；這些不在所讀文本的驗證範圍，若把容量數字當成跨市場常數，會高估可轉移性（推斷，待核）。對量化讀者，應把容量曲線與換手預算當成組合約束，而不是再用毛 Alpha 排名。

## §1 · 架構 / Core Mechanism

### 1.1 三大改動 vs 前作

| 維度 | 以往做法（導讀所述） | 本文改動 | 容量含義 |
|---|---|---|---|
| 成本函數 | 固定資金規模下測線性買賣價差 | 線性半價差 + 二次方瞬時/永久衝擊 + 盤口恢復 | 大資金成本非線性上升 |
| 數據粒度 | 固定規模/低頻回測 | NYSE 逐筆高頻；五分鐘窗口估永久衝擊、一秒鐘切片估瞬時與恢復 | 逐股逐日參數 |
| 調倉規則 | 月末全額再平衡 | 部分調整：每月只交易目標與當前權重差額的固定比例，於百分之五到百分之百搜索 | 換手與衝擊峰值平滑 |

### 1.2 ⚡ Eureka

把月度調倉的換手曲線直接接到微觀衝擊曲線上；部分調整讓線性費用按比例降、二次方衝擊按平方降，於是用可控的跟蹤誤差換容量。

### 1.3 信息流

NYSE 逐筆/報價（2010 年至 2023 年）  
→ 逐股×逐日微觀回歸（五分鐘永久、一秒鐘瞬時/恢復）  
→ 單股成本曲線：半價差 + 二次方衝擊  
→ 35 種異象月度調倉映射  
→ 可轉移 Alpha 容量曲線  
→ 部分調整（每月補百分之五）再估容量

## §2 · 數學層

📌 **Napkin Formula**（依導讀文字重構的示意式，非原文逐字）：  
`C(q) = 半價差·|q| + λ·q·q`  
直覺：q 是本月補足的權重缺口比例；線性項管價差，二次方項管大單穿透盤口的冲击。來源稱單股單日成本即「線性半價差項 + 二次方衝擊項」之和，並含瞬時衰減與永久漂移。

複雜度：逐股票×逐日估計微觀參數，再對 35 種組合做月度映射；主要成本在逐筆回歸與最優執行路徑，非端到端訓練（推斷）。Loss/訓練細節：來源未給統一 loss；微觀模型以回歸估瞬時/永久衝擊與恢復速度；ML 部分用極端梯度提升樹輸入 153 個微觀特徵預測次月收益。

## §2.5 · 帶數字走一遍（Worked Example）

以下為代數示意，不是論文實證；除來源已有的「百分之五」與「一」外不填入新數值。

1. 令目標權重 w*、當前 w0，缺口 Δw = w* − w0。全額調倉令 q = 一（來源所述退化情形）；部分調整令 q = 百分之五。
2. 交易金額 ∝ q·|Δw|；線性半價差成本 ∝ q。
3. 二次方衝擊成本 ∝ q·q；所以 q 變小時，衝擊項比線性項降得更快——這就是來源所稱的不對稱性。
4. 淨容量變化 = 節省的價差與衝擊 − 跟蹤誤差造成的毛 Alpha 損失；來源稱多數因子最優落在每月百分之五。
5. 若 q 太小，跟蹤誤差累積；若 q 太大，二次方衝擊吃掉容量。容量曲線就是在這兩端之間找折衷。

## §3 · 數據層

樣本：2010 年至 2023 年，十四年 NYSE 全量逐筆高頻，超過一千兩百萬個股票交易日樣本；五分鐘窗口回歸永久衝擊，一秒鐘切片回歸瞬時衝擊與盤口恢復。全市場股票瞬時衝擊恢復半衰期中位數約零點四秒，超過四分之一股票需半秒以上。

容量定義：以股指期貨對沖市場風險後，十四年淨值複合增長率不低於現金收益的最大初始本金（可轉移 Alpha 容量）。樣本外：所讀文本未見 train/test 切分；最佳調整速度在百分之五到百分之百搜索，是否樣本內選參待核。容量假設：月度調倉、雙邊做空、特定執行模型；借券費、交易稅、擁擠與容量擁塞未在所讀文本見到，待核。

來源沒有文獻 SOTA 對比；下表「前SOTA」欄指來源基線（全額月調倉/半年重排），不是 SOTA。

| NYSE 異象：市值加權 ML，同換手口徑（基線=半年重排） | 容量 | 十二億美元 | 六十五億美元 | +五十三億美元 |

解讀：真 capability 主要不是新預測力，而是同一信號/目標權重下的執行改善。來源明說部分調整保持選股信號與目標權重不變，因此 152→697、88→660、36→600 與 ML 容量修復應主要歸因於換手/衝擊下降，而非 Alpha 模型變強。35 種異象多頭組合中有 14 種可轉移 Alpha 容量為零、其餘 21 種具正容量；帳面 Alpha 與容量嚴重脫節：近五日最高收益率月度毛 Alpha 百分之零點四一、容量十七點九億美元；波動率調整後百分之零點二七、容量兩億三千七百萬美元；十二個月動量容量一億四千三百萬美元；淨利潤率多頭毛 Alpha 百分之零點十一、容量兩百三十一億美元。這些是不同策略，不能合成前 SOTA 或排名。

口徑警告：來源另稱營業利潤對帳面資產比率的多頭容量三百二十六億美元、經營性現金流對資產比率策略容量兩百億美元；這與上表「因子容量」不是同一口徑，不能互相加總或直接 Δ。純多頭動態資本保全容量兩千三百八十億美元是「扣除市場風險前」，不能與對沖後可轉移 Alpha 容量並列比較。多空方面，來源限定在「具備正容量的因子中」：多空中位數十五點三億美元 vs 單邊多頭十三點二億美元，稱未見實質優勢；不能推廣到零容量子集或所有市場。ML 方面，市值加權一億七千七百萬→一百八十九億三千萬；等權一千三百萬→十三億一千萬；兩者不可合併成一個「ML 組合」結論。

風險：最佳速度在百分之五到百分之百搜索，且 35 個因子中的 26 個最優落在每月百分之五；所讀文本未見樣本內外切分，存在選參過擬合可能（推斷，待核）。成本未見借券費/稅/擁擠；容量不是 Alpha，也不是跨市場常數。

## §6 · 失效與隱含假設

### 6.1 論文自述 limitations

僅讀導讀，原論文作者限制未核；不得把導讀未見當作論文沒有。以下只列導讀可見邊界：樣本為 NYSE 2010 年至 2023 年；月度調倉；35 種異象；ML 用 153 個微觀特徵；最佳調整速度在百分之五到百分之百搜索；借券費、交易稅、擁擠、樣本外切分所讀文本未見，圖表／附件待核。

### 6.2 推斷的隱含假設

- **Regime 依賴（推斷）**：容量排序依賴 2010 年至 2023 年的流動性與衝擊環境；換 regime 需重估，不能當常數。
- **容量（推斷）**：容量是模型隱含值，受盤口深度、恢復速度與執行路徑假設影響，不是物理上限。
- **成本（推斷）**：只計半價差與二次方衝擊；若借券費、稅、擁擠成本顯著，容量會下修；所讀文本未見這些項。
- **數據泄漏/選參（推斷，待核）**：最佳速度搜索未見樣本外切分；若同一樣本選速，容量增幅可能樂觀。
- **Survivorship（待核）**：35 種異象清單與股票宇宙是否含退市/生存者偏差，所讀文本未見；不能因缺失就判定有偏差。
- **部分調整滯後（條件式）**：對快速衰減信號，平滑換手會損失毛 Alpha；來源稱損失一點但衝擊節省更大，這不是所有策略必然。

**正確答**：先問容量定義（對沖市場風險後、淨複合不低於現金的最大本金），再說成本 = 半價差 + 二次方衝擊，部分調整降換手且衝擊按平方降；提到多空十五點三 vs 多頭十三點二時必須加「具備正容量的因子中」；ML 要分市值加權與等權；最佳速度搜索要問樣本外。  
**錯答**：把毛 Alpha 當容量；把 152→697 說成多頭；把 ML 一億七千七百萬→一百八十九億三千萬套到等權；說百分之五對所有策略都是最優；把容量數字當跨市場常數。

### 7.1 可證偽預測帶日期

以 2026-11-14 導讀發布為時間錨，公開復現日期 TBD；以下為研究假說，尚待驗證：

1. 在更高換手的日頻/週頻策略上，部分調整的容量增益應小於月頻基本面因子；若不然，衝擊模型或換手估計有誤。
2. 在非 NYSE 市場，最優調整比例未必落在百分之五；若多數因子仍落在百分之五，需檢查成本校準與樣本。
3. 加入借券費、交易稅、擁擠成本後，市值加權 ML 的容量增幅應收斂；若不收斂，現有容量高估。

## §8 · For the Reader

- **因子研究員**：把容量曲線加入因子報告，同時報多頭/多空/因子口徑；用部分調整做穩健性，不要只用毛 Alpha 排名。
- **高頻執行**：把恢復半衰期與瞬時/永久衝擊納入執行排程；部分調整是月度容量工具，不是日內 Alpha。
- **組合配置**：用容量約束做 sizing；對低流動性/高換手策略打折；將換手預算與部分調整寫入 mandate。
- **ML-agent/RL 策略**：高換手 ML 先用部分調整做 execution overlay；市值加權與等權分開評估；不要把 153 特徵模型的毛 Alpha 當容量。
- **研究學生**：用代數示意復現 q 與 q·q 的不對稱；先確認樣本外與成本口徑，再談最優調整比例。
