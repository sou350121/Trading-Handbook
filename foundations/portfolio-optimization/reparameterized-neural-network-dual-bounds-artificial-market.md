> **來源發布**：2026-11-04 · （無 venue） · arXiv [2611.06495](https://arxiv.org/abs/2611.06495)

**TL;DR:** ①在兩因子名目債/通膨債/股票/現金 + 定期壽險的 DC 累積問題上，用一族「人工市場」（對風險資產漂移加補償項 `v`）把凸交易約束吸收進定價核，再對偶化求原始值函數的上下界。②trick 是**不直接參數化 5 維約束量 `ṽ`，而參數化 4 維無約束 `u` 加非負 slack `s`**，經最小共同位移 `m_t` 還原可行 `ṽ`，繞開 `Σ` 近奇異（`cond₂(Σ)=29.54`）時 `Σ⁻¹` 的誤差放大；下界用 nested Monte Carlo 估條件矩 + 在**原始市場** Hamiltonian 下解 QP 回收可行策略。③對「組合執行優化」這條軸★的意義是：約束不必在策略層硬投影，可以在 pricing kernel 族上搜尋，且**對偶間隙本身就是數值解的可信度憑證**——這是它與直接策略網路（Li & Forsyth）的分水嶺。④相對對偶間隙：`γ=1.5` 時本法 `2.87`，SAMS `71.12`、Deep Pricing Kernel `48.44`；`γ=0.8` 時 `0.95` vs `66.30` / `53.21`（單位皆為 %）。

**X-Ray.** 把它放回五軸，「數據模態=量價表格」其實名不副實：它沒有人工智慧意義上的資料集，只有一組用美國月度資料校準出來的結構參數；「監督回歸」也只是外殼（網路回歸條件矩），骨子裡是帶約束的隨機最優控制加對偶界計算。所以它的分數不能按「預測準確率」讀，只能按「數值解離真值多遠」讀。它解掉的三個舊工程坑都很具體：(a) 約束下定價核不唯一、martingale 方法失效 → 用 Cuoco 人工市場把約束搬進漂移；(b) 高維下 `Σ` 近奇異，直接參數化 `ṽ` 再乘 `Σ⁻¹` 會放大誤差、破壞梯度優化 → 改參數化 `u`；(c) 四資產逐元素截斷不保證 `ι₄ᵀθ ≤ W` → 改 Hamiltonian QP。三個都屬工程層，理論骨架仍是 1992–1997 年的凸對偶。它打不開的 envelope 同樣清楚：單代表性個體（22 歲男性、高中學歷收入曲線、SSA 2022 男性生命表）、無交易成本、壽險連續可交易、死亡率確定、全樣本估參無參數不確定性。尤其 §5.5 那個「約束終期財富 `2.54\times 10^{3}` vs 無約束 `2.28\times 10^{6}`」的量級差，本質是**「槓桿不可得」**，不是「約束把策略變好了」——誤讀這一點，就會把一篇精算數值方法論文當成配置 alpha 論文。

## §1 · 架構 / Core Mechanism

### 1.1 三大改動 vs 前作

| 維度 | B1 SAMS（Bick et al. 2013） | B2 Deep Pricing Kernel（Li & Wei 2024a） | 本法 Reparameterized NN |
|---|---|---|---|
| 補償漂移參數化 | `ṽ_t = a + bt`（時間仿射） | `ṽ_t = NN(t, X_t)`，直接輸出五個受約束分量 | `(u_t, s_t) = NN(t, X_t)`，4 維無約束 + 1 維非負 slack |
| 可行性保證 | 端點非負 + 仿射 ⇒ 全時點落於 `Ã` | 網路輸出映射進非負錐 `Ã` | Prop 5.3：`m_t = [−min_j (Σu_t)_j]⁺`、`ṽ_0,t = m_t + s_t`、`ṽ_−,t = Σu_t + ṽ_0,t ι₄` |
| 上界最佳化穩定性 | 解析 ODE（Prop 5.1），無網路 | 受 `Σ⁻¹` 病態放大困擾 | 直接參數化 `u`，`Σ⁻¹` 只在必要時用於還原可行性 |
| 下界條件矩估計 | ODE 解析解 | deep pricing kernel 回歸網路 | nested Monte Carlo（每外層狀態 40 條內層路徑）+ 中央差分求 `∇_X` |
| 策略回收 | 截斷／QP | 原截斷 → 改 QP | Hamiltonian QP（用原始市場 `v≡0` 的 Hamiltonian） |
| 相對對偶間隙 `γ=1.5`（%） | `71.12` | `48.44` | `2.87` |
| 相對對偶間隙 `γ=0.8`（%） | `66.30` | `53.21` | `0.95` |

三處改動並非同一層級：參數化改的是**上界側**搜尋空間與最佳化穩定度，nested MC 改的是**下界側**條件矩估計（且 §5.3 顯示它與 DPK 回歸幾乎等價：nested MC vs DPK 回歸，`γ=1.5` 下 `2.865316%` vs `2.810315%`，`γ=0.8` 下 `0.947800%` vs `0.926117%`），QP 改的是**下界可行性**。文中唯一被單獨隔離的消融是 QP：固定其他元件、`γ=1.5` 時，把 Euclidean/`L²` 投影換成 Hamiltonian QP，下界由 `-0.067666` 抬到 `-0.052448`，相對間隙由 `24.71%` 降到 `2.87%`。

### 1.2 ⚡ Eureka

**不要把約束投影到策略上，要把約束「定價」進漂移裡；然後對偶間隙就是你的誤差條。**

直覺：在人工市場裡，替被禁方向的資產加一筆懲罰性漂移，理性個體自然不會超配；把所有懲罰參數 `v` 掃一遍取最不利的那一個，就得到原始問題的有效上界。再把上界誘導出的策略丟回**真實**市場，算出它真正能拿到的期望效用——那就是下界。兩邊夾住真值，才敢說「我算對了」；只有點估計（B3）連夾逼都給不出，宣稱的效用還掉到區間外（`-0.052975` 低於本法下界 `-0.052448`）。

## §2 · 數學層

📌 **Napkin Formula**（Eq. 21 搭配 Eq. 31 的 CRRA 半顯式形式）：

```
J̃(ψ,v) = E[ ∫₀ᵀ ₜp_x λ_{x+t} Ũ(ψ π_{v,t}) dt + ᵀp_x Ũ(ψ π_{v,T}) ]
        + ψ·{ w₀ᴿ + E[ ∫₀ᵀ ₜp_x π_{v,t}( C_tᴿ + δ(ṽ_t) ) dt ] }
對偶問題： inf_{(ψ,v) ∈ (0,∞)×N*} J̃(ψ,v)
```

**複雜度直覺**：內層 `ψ` 在固定 `v` 下嚴格凸、零點唯一（Prop 4.1），退化成一維求根；外層 `v` 才是高維——`NN(t,X_t)` 在每個時間格輸出 `u_t`（4 維）與 `s_t`（1 維）。下界側每條外層狀態要跑 40 條內層路徑，並以共同隨機數做基準 + 四個中央差分擾動（`X_i ± ε_FD e₁`、`X_i ± ε_FD e₂`）才能拿到 `∇_X F̂`；最後每步解一次 QP。整體成本是「外層路徑 × 時間步 × 內層路徑 × 擾動組數」的量級，論文報告的是 H800 GPU 總運行秒數而非 FLOP。

**直覺 2–3 句**：`Ũ` 是 CRRA 的凸共軛（`Ũ(z)=U(f(z))−z f(z)`、`f=(U′)⁻¹`），把「最優終端財富」編碼成定價核的函數，於是原始問題裡那個不可直接求解的無窮維控制，變成對定價核族取 inf 的有限維問題。對 portfolio-mix 約束，只要 `ṽ_t ∈ Ã` 就有 `δ(ṽ_t)=0`，支撐函數項在數值上直接消失——約束的全部作用，只透過「哪些定價核被允許」來體現。

**Loss / 訓練細節**（§5.3）：四種方法皆用 10,000 條路徑、210 個時間步；可訓練模型用 Adam 跑 2,000 次迭代、常數學習率 `5\times 10^{-4}`；所有網路三層隱藏層、每層 32 個神經元、ReLU；QP 用 OSQP，絕對與相對容差 `10^{-9}`、最大 10,000 次迭代。B1 不含神經網路，直接最佳化仿射參數。

## §2.5 · 帶數字走一遍（Worked Example）

> **以下全部數字為示意假設，用單資產標量版本以手算演示 Prop 5.3 的位移邏輯；不是論文實證結果，也不對應論文的四資產校準值。**

假設（示意）：把四風險資產縮成 1 個，`Σ = σ = 2`（標量）；某時刻 `(t, X_t)` 上網路輸出 `u_t = -0.75`、`s_t = 0.25`。

1. **算 `Σu_t`**：`2 × (-0.75) = -1.5`。這個量若直接當 `ṽ_−` 用，會違反非負約束。
2. **算最小共同位移**：`m_t = [−min_j (Σu_t)_j]⁺ = [−(−1.5)]⁺ = 1.5`。直覺：要讓 `Σu_t` 每個分量都 ≥ 0，最少要整體往上平移「最大負偏量的相反數」。
3. **補上 slack**：`ṽ_0,t = m_t + s_t = 1.5 + 0.25 = 1.75 ≥ 0`。`s_t` 是網路可學的額外鬆弛，等於容許它把有效短率再往上挪一點。
4. **還原 `ṽ_−`**：`ṽ_−,t = Σu_t + ṽ_0,t·1 = -1.5 + 1.75 = 0.25 ≥ 0`。於是 `(ṽ_0, ṽ_−) = (1.75, 0.25)` 落在 `Ã`，`δ(ṽ)=0`，可行。
5. **接到定價核與兩側**：由 (17)/(34) 反解 `v_t`，構成 `π_{v,t}`；上界側對 `ψ` 解一維凸最小化（Eq. 25）得 `ψ_v`，再對 `v`（即網路參數）最小化 `J̃`；下界側用 nested MC 估 `F̂₁`、`F̂₂` 與 `∇_X F̂`，得候選策略 `y_t`，最後 QP 投影到 `{θ ≥ 0, ι₄ᵀθ ≤ W_tᴿ}`。
6. **對照反例**：若改成「先輸出 `ṽ` 再乘 `Σ⁻¹`」，同一個 `u` 擾動在 `Σ` 近奇異時會被放大成 `v` 的大跳動——這正是論文改用 `u` 參數化的動機（`cond₂(Σ)=29.54`）。

**解讀：哪些是真 capability**
- 相對間隙的收縮在兩個 `γ`、對兩個基線都同向且幅度大，這是本頁認為最扎實的部分：它是**數值解可信度**的提升，不依賴任何策略績效假設。
- 被隔離的因果只有一條：Hamiltonian QP（`γ=1.5`，其他固定，下界 `-0.067666` → `-0.052448`）。把全部 gap 收縮歸因於「重參數化」在證據上不夠——重參數化對上界最佳化穩定性的貢獻，文中只有定性描述（改善穩定性），沒有對應的單獨消融。
- 下界條件矩估計器的選擇**幾乎不影響**結果（nested MC vs DPK 回歸，`γ=1.5` 下相對間隙 `2.865316%` vs `2.810315%`；`γ=0.8` 下 `0.947800%` vs `0.926117%`）。這反而是對從業者有用的負面結果：這一層不需要發明新網路。

**哪些可能是假象或未計項目**
- 這是模型內蒙地卡羅，沒有樣本外，因此不存在「過擬合歷史資料」的問題，但存在**「擬合校準參數」**的問題：Table 1 中多個參數 p 值偏大，點估計誤差會直接傳導成最優倉位/保費形態的偏移，論文未做參數不確定性下的穩健性檢驗（所讀文本未見）。
- 交易成本完全未計（§6 自列為 future work）。約束解「不舉債、不做空」在這個無摩擦世界裡是監管合規的體現，但一旦加上成本，無約束解中那巨額空頭短債的部位在實務上更不可能執行——這反而強化論文結論方向；不過「約束解 vs 無約束解」的財富量級差（`2.54\times 10^{3}` vs `2.28\times 10^{6}`，`γ=1.5`）本質是槓桿可得性的差，不是策略優劣的差。
- 時間成本高於 B1 與 B3：本法 `870.62` 秒（`γ=1.5`）/ `874.75` 秒（`γ=0.8`），B1 `371.07` / `378.31`、B3 `432.05` / `460.33`。間隙收縮幅度見上表 Δ；這是一筆值得但並非免費的交易。

## §6 · 失效與隱含假設

### 6.1 論文自述限制（可定位）

- **§6 Conclusion**：交易成本與更細緻的借貸限制留待未來（「introduce transaction costs and more detailed borrowing limits to study implementation」）；壽險應改為離散契約（「replace the continuously traded insurance position with discrete contracts」）；死亡率應改隨機（「introduce stochastic mortality」）。三項皆為本文模型外。
- **§2.4**：刻意不對 `I^{R}_t` 加非負約束——`I^{R}_t < 0` 被解釋為年金需求，加上非負約束會抹掉 DC 計劃中的個人年金需求。
- **§5.3**：`Σ` 近奇異，`cond₂(Σ)=29.54`；反向映射病態時，`ṽ_t` 的小誤差會造成補償漂移大跳動並破壞梯度優化。
- **§5.3**：四資產下逐元素截斷不能保證 `ι₄ᵀθ ≤ W`，這是 Li & Wei (2024a) 原做法在本設定下的失效點（作者對他人方法的限制陈述）。
- **§5.3**：財富更新的正部算子只是對時間離散誤差的數值保險，且在「全部 10,000 條路徑」中該算子套用前財富已非負——這是經驗陳述，非證明。
- **§5.2.1 Remark 5.1**：若改用人工市場 Hamiltonian 回收策略，相對間隙會由 `2.87%` 增至 `6.24%`——即策略回收必須在原始市場做。

### 6.2 本頁推斷的隱含假設（明標推斷，非作者陳述）

- **【推斷】參數即真值**：Kalman filter 的點估計被當作真實市場參數使用，無 parameter uncertainty / ambiguity aversion、無貝葉斯後驗。對 45 年期限的配置問題，這一條比任何演算法細節都更決定結論。放寬後 `2.87` 這個間隙數字不會變（它只衡量數值誤差），但最優策略形態會變。
- **【推斷】單一代表性個體**：22 歲男性、高中學歷收入曲線、SSA 2022 男性生命表。對女性、其他教育/收入組、有配偶與否的個體，壽險需求的 hump 峰值時點與股票部位路徑無遷移性保證；論文未做分組敏感性（所讀文本未見）。
- **【推斷】無摩擦與連續時間**：連續交易、連續可交易壽險、無保費加載（所讀文本只給面值 `I_t/λ_{x+t}`，未見 loading 項）、無稅、無流動性限制、無再平衡摩擦。這些不是「小扰动」——§5.5 已顯示無約束解的倉位量級完全脫離實務。
- **【推斷】理論與實驗的覆蓋落差**：理論章節對一般非空閉凸集 `A` 成立，數值只跑 long-only 特例。對含「不可交易資產」「最低資本要求」等其他凸約束的表現，**未測試 ≠ 已證明無效**，但也不應外推。
- **【推斷】模型類別封閉**：兩因子 OU + 常係數 + 布朗驅動，無 regime switching、無跳躍、無隨機波動率、無模型不確定性。利率與通膨因子可為負（作者明說與美國負實質利率/通縮歷史一致），但這只是分佈支撐，不是結構性斷點處理。
- **【推斷】死亡率獨立性**：死亡率獨立於金融濾流是建模便利，長壽風險與市場風險的相關性未被檢驗。

## §8 · For the Reader

- **組合配置 / LDI 與養老金從業者**：這是最直接的讀者。重點不在 §5.3 的 gap 表，而在 §5.4–5.5：long-only 約束下臨近退休的股票部位約 `1.65\times 10^{3}`（`γ=1.5`）與 `2.06\times 10^{3}`（`γ=0.8`），短期名目債部位在兩種風險偏好下都貼近零；對照無約束解，`γ=1.5` 的期望終期財富從 `2.54\times 10^{3}` 被放大到 `2.28\times 10^{6}`。實務含義是：任何以無約束閉式解為基礎的 glide path 建議，都系統性高估了可執行性。
- **因子 / Alpha 研究員**：這不是 alpha 論文，不要拿它的數字當績效。可借的只有一個觀念——**用上下界夾逼來驗收你的數值解**；當你的策略求解器只能給點估計時，你無法區分「策略好」與「求解器收斂到錯的地方」。
- **高頻 / 執行端**：主體無關，但那個 QP 值得抄：`min_θ (θ−y)ᵀ ΣΣᵀ (θ−y) s.t. θ ≥ 0, ιᵀθ ≤ W` 是一個帶協方差度量的投影算子，可以直接搬到「執行端倉位/額度約束下、把想要的目標組合拉回可行域」的問題；論文也明確說它優於 Euclidean/`L²` 投影（下界 `-0.067666` → `-0.052448`）。
- **RL / 隨機控制研究者**：把它當高維帶約束控制的 baseline。兩個值得記住的負面結果：(a) 直接策略網路（B3）在需要精細結構（保費 hump、`(32)/(33)` 這種半顯式形式）時學不出來；(b) 免調參的 nested MC 在條件矩估計上與精心設計的回歸網路**打平**（`γ=1.5` 下 `2.865316%` vs `2.810315%`，`γ=0.8` 下 `0.947800%` vs `0.926117%`），所以那一層不必發明新網路。
- **研究學生**：閱讀順序建議 §3 的 Theorem 3.1（靜態預算約束族 ⇔ `A`-可行性，這是全篇支點）→ §5.3 的 Table 3 → 再回頭啃附錄 A 的對偶證明。不要從附錄進去，會迷失在支撐函數與停止時間的技術細節裡而抓不到主線。
