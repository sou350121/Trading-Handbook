# agent_skills/socratic-tutor 解構（agent_skills/socratic-tutor）

> **導讀發布**：2026-11-10 · （無 venue）
> **QuantML 導讀**：[Jane Street 开源：竟然是一个“只提问”的 AI](https://mp.weixin.qq.com/s?__biz=Mzg2MzAwNzM0NQ==&mid=2247494870&idx=1&sn=23c83456a9767966f9b3ac356bd7e98b&chksm=ce7d8bc8f90a02de8cd39e8bbb74e0cbe0658cd32ddacea8ef0031f1823b76bda5fadd32ae96#rd)
> **核心定位**：五軸落點在「文本另類 × 跨周期 × 生成式大模型 × 因子挖掘 × 人機協同可解釋」——但這是一套**以提問為內容的 Agent 交互規約**，不是 alpha 模型、也不是回測論文。它補的不是因子挖掘的 prior gap，而是「通用 LLM 長篇作答造成掌握錯覺、缺少邊界推演」這個使用層缺口。

**五軸座標**

| 數據模態 | 時間尺度 | 學習範式 | Alpha機制 | 人機協作 |
|:-:|:-:|:-:|:-:|:-:|
| `文本另类` | `跨周期` | `生成式大模型` | `因子挖掘` | `人机协同可解释` |

**Status:** v0.5 — 基於QuantML 導讀（有原文則以原文為準）。細節待升 v1。
**TL;DR:** ① 把 Jane Street 風格的「連續追問、只逼你自己推邊界」固化成 `socratic-tutor` 技能規約：意圖過濾、單題推進、沉默約束、前置診斷、0–5 級掌握度地圖。② 核心 trick 是「一次只問一題、問完即停、答對偶爾扮反方」，讓模型的輸出重心從答案轉移到下一個問題。③ 對「人機協同可解釋」軸★的直接貢獻是：把可解釋性放在問題結構與判分地圖上，而不是答案文本上。④ **來源未給量化績效結果**——導讀含診斷題的假設數字，單次演示另有「模型對學習者的掌握度評級」（4/5、4/5、3/5、3/5，overall 70%），那是學習者診斷結果，不是模型/策略 benchmark。

**X-Ray.** 這東西的工程價值不在模型，而在**狀態機設計**：把「診斷—判分—追問—反駁」抽成一組可複用指令，用沉默把推理負擔強制推回學習者。它解掉的舊坑很具體：通用 LLM 一次幾千字、讀者被動順著行文走、遇到約束條件變化或微小數據偏差仍會踩同樣的坑。它打不開的 envelope 同樣清楚：沒有訓練迴圈、沒有獨立評估協定、底層 LLM 及其預訓練截止日完全未披露；地圖是**模型對學習者的評級**，其校準性未經驗證。對量化讀者的意義是把它當「防泄漏/防過擬合的自我審訊清單」，而非 alpha 來源或研究自動化工具——導讀的實測也只是單用戶、單主題的一次演示。

## §1 · 架構 / Core Mechanism

### 1.1 三大改動 vs 前作

| 維度 | 典型通用 LLM 問答 | `socratic-tutor` |
| --- | --- | --- |
| 觸發 | 任何問題直接作答 | 意圖過濾；只有系統性學習指令才啟動教學循環 |
| 節奏 | 一次輸出長篇 | 單題推進，一次一題，提問後立即停止 |
| 提示 | 常附思路/範例 | 沉默約束，問題後不帶提示與參考思路 |
| 起點 | 從問題直接講 | 前置診斷 3 至 5 道難度梯度題 |
| 評估 | 無狀態 | 0 至 5 級掌握度地圖（ASCII 字元圖） |
| 反饋 | 順勢肯定 | 答對也偶爾扮反方，檢驗極端邊界 |

### 1.2 ⚡ Eureka

**一句話**：把「導師」拆成「出題器 + 判分器 + 沉默約束」，讓模型不再用答案證明自己懂，而是用下一個問題逼出學習者的邊界。
**直覺**：單題 + 等待 = 學習者必須先給出可被反駁的承諾；有承諾才有可診斷的錯誤，沒有承諾只有閱讀。

### 1.3 信息流 ASCII 圖

```
學習者輸入
   │
   ├─ 意圖過濾：單次詢問 → 常規作答（不進迴圈）
   │
   └─ 系統性學習指令 → 診斷
          │
          ├─ 3 至 5 道難度梯度摸底題（一次一題、不解釋、不提示）
          │
          ├─ 判分 → 0 至 5 級掌握度地圖（ASCII）
          │
          ├─ 依最弱子項選切入點 → 給第一道深層推導題
          │
          └─ 迴圈：答對也偶爾扮反方 → 更新地圖
                     （`just tell me` 可臨時跳出當前題）
                     （`save state` → 文本塊 → `resume from:` 續接）
```

## §2.5 · 帶數字走一遍（Worked Example，示意）

以下把導讀中的單次演示壓成可照算的流程；**數字全部取自導讀文本，流程為解構示意，不是論文實證**。

1. **輸入指令**（逐字）：`/socratic-tutor teach me 如何在时序因子特征工程中彻底避免数据泄漏与过拟合`。
2. **拆維度**：源文本說模型拆成四個維度——時點對齊與發布時滯、滾動窗口的時間截斷、交叉驗證淨化、多重測試偏差檢驗。
3. **逐題診斷**：四道連續診斷題，一次一題。以第一題為例，題面日期為 2025 年 12 月 31 日（年報截止）、次年 4 月 10 日（審計簽署）、4 月 14 日晚間 20:00（實際披露）；源文本給出的正確生效時點是 **2026 年 4 月 15 日盤前**。注意：原文對這段時差用了「四個多月」的表述，讀者需自行對照上述日期；本頁不做日期反算。
4. **判分渲染地圖**：四項得分在源文本中依次為 4/5、4/5、3/5、3/5，`overall: 70%`。導讀未說明 70% 的計算方式。
5. **選切入點**：源文本標註第三項「淨化交叉驗證與標籤去重疊」為「建議起點」（3/5），並給出下一道追問（測試集在時間軸上排在訓練集前面，為何仍需插入隔離期刪掉訓練集開頭）。這一步就是「單題推進」的具體體現：不給答案，等學習者給出可被反駁的解釋。

### 6.2 推斷的隱含假設（以下均為推斷，尚待驗證）

- **模型判分是可校準的**：地圖分數來自模型對學習者答案的評級；源文本未給評分規則或一致性檢驗。
- **沉默約束真的能逼出推理**：假設「不給提示」會讓學習者調用推理，而不是直接猜或上網查。未做對照。
- **單題推進在長主題上可持續**：假設多輪追問後上下文不退化；源文本未披露上下文管理。
- **跨主題可移植**：演示只有一個主題（時序因子防泄漏），不能外推為「適用所有技術主題」。
- **反方質疑不等於事實正確**：源文本中「提前四個多月」與其自身題面日期存在表述不一致（見 §2.5），提示模型扮演反方時仍可能給出內部不自洽的斷言。
- **無倖存者偏差陳述**：源文本沒有提供任何資料集或樣本選擇過程，因此此項不適用，而非「已排除」。

## §8 · For the Reader

- **因子研究員**：把它當「防泄漏自審清單」的交互化版本——用它逼自己對時點對齊、滾動窗口截斷、淨化交叉驗證、多重測試各給一次可被反駁的解釋；不要把它的地圖分數寫進研究報告當績效。

- **組合配置**：可把它當研究流程的「提問腳本」；它不提供資產配置或風險預算方法。
