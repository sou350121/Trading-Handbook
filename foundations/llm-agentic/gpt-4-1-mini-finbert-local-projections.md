## §1 · 架構 / Core Mechanism

### 1.1 三大改動 vs 前作

| 維度 | 前作（標量總情緒／無監督主題） | 本文做法 | 為什麼是改動而非調參 |
|---|---|---|---|
| 聚合粒度 | 全語料壓成一個情緒標量 | 十二個預設經濟主題，各建月度正向／負向指標 | 把「注意力分配」與「原始基調」在結構上分離 |
| 衝擊識別 | 直接用情緒水平或詞頻密度 | 二階段：第一階段回歸取條件殘差作為「意外衝擊」 | 剝離實體基本面本身的機械不對稱（衰退比復甦更急） |
| 動態刻畫 | 當期係數／事件窗均值 | 局部投影追蹤十二個月，算排除當月的累積持續性與半衰期 | 從「有沒有影響」升級為「影響衰減多快」 |
| 主題標註 | 無監督（LDA／聚類） | GPT-4.1-mini 對標題做十二類別映射 | 類別具經濟語義、可跨期比較；但引入模型分類誤差 |

### 1.2 ⚡ Eureka

**一句話 trick**：把「情緒」換成「情緒的**意外**成分」，再讓它對**每個主題、每個方向**各自跑一條十二個月的脈衝響應——不對稱不在均值裡，在衰減曲線裡。

直覺：總指數是「議題混合比例 × 各議題情緒」的乘積項。混合比例會因為採編篇幅而漂移，於是標量下跌可能只是版面權重變了。拆到主題維度後，殘差化保證你比的是同一種東西（同一個 SD 的意外衝擊），累積持續性才可跨主題比較。

### 1.3 信息流

WSJ 標題（1990–2025，逾 132 萬篇）
→ GPT-4.1-mini 分類 → 主題標籤 k ∈ {十二個經濟主題}
→ FinBERT 對開頭核心段落打分（極性 + 置信度）
→ 月度聚合：每主題 正向指標 / 負向指標
→ 第一階段回歸：控制 自身滯後情緒、美股大盤回報、VIX、工業產出增速、兩年期美債收益率變動、當月該主題版面佔比、其他主題留一法情緒
→ 條件殘差 ε → 標準化為衝擊 z
→ 第二階段 local projections：h = 1…12 逐期回歸
→ 累積持續性 P（排除 h=0）＋ 半衰期
→ 主題間橫向對比：好消息 P vs 壞消息 P

## §2 · 數學層

📌 **Napkin Formula**（依導讀描述重建，原論文方程未核）

第一階段（衝擊識別）：
`s_{k,t} = Γ·X_{k,t} + ε_{k,t}`，`z_{k,t} = ε_{k,t} / σ(ε_k)`
其中 `X` 含自身滯後情緒、宏觀金融控制、版面佔比、其他主題留一法情緒。

第二階段（局部投影）：
`y_{t+h} = α_h + β_{k,h}·z_{k,t} + controls + u_{t+h}`，`h = 1…12`
累積持續性：`P_k = Σ_{h=1}^{12} β_{k,h}`（排除 h=0 當月）

複雜度：文本端為一次性 GPT-4.1-mini 分類 + FinBERT 打分（成本未披露）；計量端是 十二主題 × 兩方向 × 十二個 horizon 的逐期 OLS，量級極輕。

**直覺**：`β_h` 是「一個標準差意外情緒，h 個月後還剩多少」。`P` 是這條曲線下面積（去掉起點）。P 大＝敘事有後勁；P 近零＝見報即被遺忘。

**Loss／訓練細節**：本文**不訓練**任何預測模型。GPT-4.1-mini 為現成模型做標題分類（提示詞、few-shot 與否、驗證集準確率：所讀文本未見，圖表／附件待核）；FinBERT 為金融語料微調模型（微調語料與超參未披露）。因此 §3 所說的時間邊界須分列：**預訓練截止日未披露；分類／打分為推論階段（適配後權重）；主題擬合（回歸估計）樣本期為 1990 年至 2025 年**——三者不可互相代稱。

## §2.5 · 帶數字走一遍（Worked Example）

⚠️ 以下為**假設／示意**流程，非論文實證結果；依數字紀律，本頁不注入自造數值，走一遍用符號，量級錨點全部取自導讀逐字數值。

1. **假設**一則頭條被判為主題 k = 金融市場，FinBERT 給出負向分數 `s`（示意，符號化）。
2. **第一階段**：用該主題自身滯後情緒、宏觀金融控制、當月版面佔比、其他主題留一法情緒回歸 `s`，取殘差 `ε`；把 `ε` 除以自身標準差得到 `z`——即「一個標準差的意外負面衝擊」。
3. **第二階段**：對 `h = 1…12` 逐期回歸，得到 `β_1, β_2, …, β_12`。
4. **累積**：`P_neg = Σ_{h=1}^{12} β_h`（排除 h=0）。
5. **重複**同一流程於正面衝擊，得 `P_pos`；比較 `P_neg` 與 `P_pos`。
6. **讀數對照（導讀逐字量級）**：金融市場負面衝擊半衰期 1.2 個月、正面 0.7 個月；國內宏觀經濟與增長 `P_pos = 0.072`、`P_neg = 0.098`；安全、公共健康、環境與氣候的壞消息 `P` 在 0.08 左右；金融市場、企業戰略、房地產的壞消息 `P` 達 0.11 到 0.12 以上。

### 6.2 推斷的隱含假設（明標推斷）

1. **主題分類誤差為隨機**（推斷）：若 GPT-4.1-mini 的誤分類與語氣相關（例如負面報導更易被歸入「公共安全」），衰減估計會被系統性污染，方向未知。
2. **開頭段落可代表全文情緒**（推斷）：長篇深度報導與短訊的壓縮損失不同，可能在「壞消息更粘」的結果中混入篇幅效應。
3. **條件殘差＝結構衝擊**（推斷）：local projections 本是預測性回歸；把殘差稱作「衝擊」需要控制變量完備。此為因果結構軸上的最大軟肋，且**只適用於本文控制集，不可跨系統斷言**。
4. **版面佔比可作注意力控制**（推斷）：但版面佔比本身可能是情緒的結果（媒體回應讀者需求），存在同時性。
5. **月度聚合不丟資訊**（推斷）：若壞消息的衰減发生在前幾週，月度採樣會低估差異——即本文結果可能是**下界**；此為推斷，未驗證。
6. **regime 穩定性**：只測了衰退交乘。其他結構斷點（例如社交媒體普及後的敘事傳播機制變化）未見檢驗——所讀文本未見，待核。
7. **單一媒體外部效度**（推斷）：WSJ 讀者結構與採編政策特定；這屬**媒體選擇偏差**，不是 survivorship bias——本文不涉及主體存續筛選。
8. **可交易性缺口**（推斷）：無成本、無容量、無換手約束，故本頁不主張任何 alpha 存在性。

### 7.1 可證偽預測（以導讀發布 2026-10-06 為起算基準，時點未定）

- **P1**：若有人用同一 WSJ 語料、同一殘差化流程建主題多空情緒因子，並對壞消息主題使用更長半衰期加權，則在一輪獨立複現中應優於單一半衰期的標量情緒因子。若結果反向或不顯著，則「差異化衰減有實務增益」被否證。
- **P2**：若在 2026-10-06 之後滾動延長樣本，金融市場主題的負面衝擊半衰期不再高於正面衝擊半衰期，則「高頻資訊供給未加速敘事均值回歸」被否證。
- **P3**：若換用非 WSJ 語料（或加入社交媒體）後，十二主題的不對稱排序不穩定，則本結果的外部效度降級——但這只削弱可推廣性，不否證 WSJ 樣本內的估計。

## §8 · For the Reader

- **因子研究員**：直接把「半衰期」當超參來用——按主題分層設 decay，別在全樣本共用一個 halflife。先做的最小實驗是：把現有情緒因子按主題拆開，看 decay 掃描的最優點是否真的隨主題漂移（此為待驗證假設，不是本文結論）。
- **高頻執行**：本文是月度頻率，對日內／Tick 無直接指導；但「資訊流量大 ≠ 衰減快」值得作為 microstructure 外的對照組，別把新聞到達率當作噪聲衰減率的代理。
- **組合配置**：把總情緒指數當風險偏好代理時，先做「議題權重歸因」——若指數下跌主要來自高粘性議題的版面佔比上升，壓制時間會遠超普通事件（導讀結論的實務引申，尚待驗證）。
- **LLM-agent 研究者**：本文是「LLM 做標註、計量做推論」的分工範式；值得借的是**不讓 LLM 直接輸出結論**，而讓它只輸出可進回歸的標籤與分數，把不確定性留給統計層。
- **RL 策略**：可把主題半衰期做成狀態特徵（state feature）而非獎勵塑形，避免把測量偏誤寫進 reward。
- **研究學生**：這篇是 local projections + 二階段殘差化的乾淨教學案例；重點學「如何把一個質性直覺（壞消息更粘）拆成可估參數（P 與半衰期）」，以及「穩健性檢驗要針對最強的反對假設設計」。
