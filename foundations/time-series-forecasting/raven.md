# RAVEN 解構（RAVEN）

> **導讀發布**：2026-09-22 · （無 venue）
> **QuantML 導讀**：[黑翼资产｜告别固定窗口：自适应时序架构 RAVEN](https://mp.weixin.qq.com/s?__biz=Mzg2MzAwNzM0NQ==&mid=2247494608&idx=1&sn=b7b597629812f2a7579d048d55ddcd7f&chksm=ce7d8ccef90a05d8538d0b47d9e9c428442362241d167b1e4f5d857de28fff40fddebf9f3f65#rd)
> **核心定位**：五軸落點＝量价表格／日频波段／监督回归／端到端表征／全自动黑盒。它補的 prior gap 不是「模型不夠大」，而是**「回看窗口該多長」這個被當成超參數而非變量的默認設定**——把 window length 從人為常數改成 sample-wise 的隱變量。

**五軸座標**

| 數據模態 | 時間尺度 | 學習範式 | Alpha機制 | 人機協作 |
|:-:|:-:|:-:|:-:|:-:|
| `量价表格` | `日频波段` | `监督回归` | `端到端表征` | `全自动黑盒` |

**Status:** v0.5 — 基於 QuantML 導讀（有原文則以原文為準）。細節待升 v1。
**TL;DR:** ①把量價序列逆時序排列，用輕量 MLP 給每個切片打重要性分，沿時間往回累積，按三級遞增門檻切出**嚴格嵌套**的短／中／長前綴，分派給三個時間尺度專家。②核心 trick 是「前綴嵌套＋表示解耦」：長窗口物理上包含短窗口，所以必須用餘弦相似度感知加權、路由負熵正則、專家多樣性正則強行把三路表徵推開，否則退化成單尺度。③對「端到端表征 × 日频波段」這條軸★的意義是：多尺度不再是人工網格搜索，而是由當日資訊密度自證。④來源未給出可機械核驗的量化結果（導讀正文的 IC／ICIR／累計超額數值在原文以轉義字元書寫，未經原論文核對），本頁一律標未披露。

**X-Ray.** 放在五軸 Pareto 上，RAVEN 不是新 backbone，而是**對「輸入構造」這一層動刀**：PatchTST／TimesNet／iTransformer 都在改表徵與注意力，卻共同接受了「固定 lookback」這個前提。它解的舊工程坑很具體——多尺度特徵拼接（HAR 系）參數寫死、無法隨波動率聚類自適應；長窗口餵雜訊、短窗口漏結構的兩難。真正值得量化讀者注意的不是 MoE，而是**嵌套前綴**：它把「稀疏路由」從特徵空間搬到時間軸，保證每個專家看到的是連續、以最新時點為錨的片段，避免了內容稀疏把時序語義切碎。但它的 envelope 也清楚：自適應完全由單票自身歷史驅動，導讀自己就點明「無法察覺期指基差貼水或微盤流動性踩踏」——這是 alpha 層的局部解，不是風控層的解；且重要性打分器與預測頭聯合訓練，若打分頭能看到預測窗內的資訊，整條「自適應」就是泄漏的美化。對讀者的意義：可借的是**輸入長度作為可學習變量**這一思路，可抄的是嵌套前綴的工程實作，不可抄的是把單一實盤帳戶的超額當成架構因果。

## §1 · 架構 / Core Mechanism

### 1.1 三大改動 vs 前作

| 改動 | 前作（PatchTST / TimesNet / iTransformer / MLF 系） | RAVEN | 解決了什麼 |
|---|---|---|---|
| 上下文長度 | 固定回看窗口（窗口長度：未披露） | 逆時序重要性累積 → 三級遞增門檻切出嵌套前綴，長度 sample-wise 動態 | 暴漲暴跌自動縮窗、慢牛自動拉長 |
| 專家分工軸 | 通道獨立／固定週期多尺度拼接（HAR 式日／週／月） | 短／中／長三個**時間尺度**專家，前綴嚴格嵌套（短 ⊂ 中 ⊂ 長） | 保住位置注意力連貫性，不切碎時序 |
| 冗餘控制 | 平均加權或 Softmax 門控 | 餘弦相似度感知加權（推斷期）＋路由負熵正則（輸入端）＋專家多樣性正則（輸出端） | 抗共線性、抗路由坍塌 |
| 全局兜底 | 無獨立分支 | 額外一條對最大回看窗口做全局自注意力的壓縮表徵分支，與局部專家輸出拼接 | 專家分歧時仍有宏觀視野 |

### 1.2 ⚡ Eureka

**「不要問回看多久，問資訊累積到哪裡就夠了。」** 直覺：把切片按「離今天多近」排序後，重要性曲線是單調上升的；曲線**陡**＝最近幾天資訊密度高（恐慌、放量）→ 很早撞線 → 只用短前綴；曲線**平**＝近期都是雜訊、趨勢要看更遠 → 要走很深才撞線 → 自然拉出長前綴。窗口長度不是被預測出來的，是被**曲線與門檻的交點**決定的副產物。

## §2 · 數學層

📌 **Napkin Formula**

```
a_i = MLP(x_i),            i 由最新往回編號
S_k = Σ_{i=1..k} a_i,      P_j = {x_1..x_{k_j}},  k_j = min{k : S_k ≥ τ_j}
w_j ∝ c_j · exp(−α · Σ_{m≠j} cos(h_j, h_m))
L = L_pred − λ_ent·H(a) + λ_div·Σ_{j≠m} cos(h_j, h_m)
```

複雜度：打分管 O(T·d) + 各專家編碼，量級與「固定窗多尺度集成」同階（實測 FLOPs／延遲：未披露）。

**直覺**：第一式把「重要性」變成可微的門；第二式讓窗口長度成為資料的函數而非超參；第三式在推斷期把「跟別人長得像」的專家的票數按指數壓下去；第四式兩項正則分別防輸入端路由坍塌（熵不能被壓到極低）與輸出端表徵退化（專家向量要走向正交）。**關鍵張力**：`−λ_ent·H(a)` 若權重過大，重要性趨於均勻 → 所有人拿到一樣長的前綴，自適應失效；過小則全堆在第一個切片。`λ_ent`、`λ_div`、`α` 的取值與搜尋範圍：未披露。

**Loss / 訓練細節**：預測目標為未來十日的累計對數收益率（導讀原文）；優化器、學習率、epoch、專家數量以外的寬度配置：未披露。

## §2.5 · 帶數字走一遍（Worked Example）

> ⚠️ 以下全部為**假設／示意**數字，只為把機制跑通，**不是論文實證結果**；論文真實數字一律留在 §5，缺者標未披露。

**示意 A（恐慌日，曲線陡）**：4 個切片，重要性 `0.45 / 0.30 / 0.15 / 0.10`（假設）。
1. 累積：`0.45 → 0.75 → 0.90 → 1.00`。
2. 設門檻 τ = `0.3 / 0.6 / 0.9`（假設值）。
3. 交點：短專家 k=1（首個 ≥0.3）；中專家 k=2（首個 ≥0.6）；長專家 k=3（首個 ≥0.9）。→ 三個專家看到 `{1} ⊂ {1,2} ⊂ {1,2,3}`，**有效回看被壓到 3 個切片**。

**示意 B（平穩日，曲線平）**：6 個切片，重要性 `0.08/0.09/0.10/0.12/0.11/0.10`（假設）。
1. 累積：`0.08 → 0.17 → 0.27 → 0.39 → 0.50 → 0.60`。
2. 同門檻下，長專家要到最後一個才撞 0.6（若還沒到就繼續往歷史深處走）→ 有效回看被拉長到接近整個窗口。

**示意 C（冗餘懲罰）**：若 `cos(h_s,h_m)=0.95`、`cos(h_s,h_l)=0.10`（假設），α 取任意正值 → 中專家的權重被 `exp(−α·0.95)` 壓得比長專家更狠，即使它的原始置信度更高。**這一步就是「不讓長窗包含短窗」變成「不讓兩個專家說同一句話」。**

## §6 · 失效與隱含假設

### 6.1 論文自述 limitations

**原論文作者自述的限制條款未核**（本頁只讀到 QuantML 導讀，未見 paper 的 limitations 章節）。導讀以「核心觀點」形式轉述了四條邊界，其中第四條實質是作者側承認的能力邊界：**單資產自適應無法替代全市場系統性風控**——模型動態感知完全依托單票自身歷史量價，察覺不到期指基差大幅貼水、微盤流動性踩踏；全市場無差別殺跌時仍需組合層外部硬約束。其餘三條（有效尺度不平稳、嵌套拓撲保連貫、去共線性優先於堆參數）是動機陳述而非限制陳述。**導讀未提及不等於論文沒有寫；此處為覆蓋缺口，不是否定證據。**

### 6.2 推斷的隱含假設（明標推斷）

- **【推斷】打分器不看未來**：整套機制默認重要性 MLP 的輸入嚴格截斷在預測時點之前。若切片構造或實例歸一化引入預測窗統計量，「自適應變長」會退化為「用未來資訊選擇性回看」，這是最致命的泄漏面，導讀未交代，待核。
- **【推斷】regime 依賴**：機制假設「近期切片的重要性可加、且累積曲線能表徵資訊密度」。在重要性分佈均勻（無明顯資訊密度差異）的行情裡，三個門檻會在相近的 k 上全部觸發 → 三專家輸入幾乎相同 → 系統退化為單尺度＋一個全局分支。此時 RAVEN 與固定窗模型的差距應收斂，這是可測的失效模式，但導讀未給分 regime 的分解。
- **【推斷】容量與成本**：所有評測均未披露 AUM／換手率／衝擊成本，因此「十個百分點以上」的實盤超額在何種容量下成立未知；不可外推到更大資金或更高換手標的。
- **【推斷】共線性正則的雙面性**：強制專家正交，在有真實多尺度結構時是去噪，在單一尺度主導時是**主動丟棄有效共識**。λ_div 偏大可能讓長專家為了「不像短專家」而學到純噪聲，這一點消融未覆蓋。
- **【推斷】生存者偏差**：使用歷史成分股是減輕而非消除；被併購、退市、長期停牌樣本的處理方式所讀文本未見。
- **【推斷】跨市場可移植性**：A 股與美股共享同一組門檻與同一套專家數，若兩市資訊衰減速度不同，等於對其中一市做了隱性錯配；導讀未給分市場超參。

- **問**：「這個方法的核心貢獻是什麼？」
- **好的答法**：「它把 lookback 從超參變成隱變量：對逆時序切片打分、累積、按遞增門檻切出嵌套前綴，短中長三個專家共享同一份連續歷史的不同深度。真正的工程難點不在路由，而在**嵌套必然帶來的輸入重疊**——所以它必須用餘弦相似度加權＋熵正則＋多樣性正則三件套來防止退化成單尺度。評估時我會先看 IC 與 ICIR 是否同步改善，再看剝離路由後是否真的掉，最後才看組合層超額。」
- **錯的答法**：「又一個 MoE，堆專家提容量／把固定窗口換成多窗口集成。」——前者忽略時間軸路由這個關鍵差異，後者直接把「自適應」降級為「多尺度平均」，正好是論文要解決的共線性問題本身；且說不出嵌套前綴為何必須配解耦正則。

### 7.1 可證偽預測

- **2026-12-31 前**：若未釋出任何代碼／配置／門檻與正則係數，則本工作應歸類為「工業報告級證據」，復現性判負，讀者只可借思路不可借結論。
- **2026-12-31 前**：若原論文未給出「前綴長度 k 的分佈統計」（不同 regime、不同市值分組下的 k），則「自適應」與「固定多尺度集成」在觀測上不可區分，核心 novelty 無法成立。
- **可做的判別實驗**：把 τ 固定成等距常數、其餘不變跑同一回測。若性能不變 → 增益來自多尺度集成與解耦正則，而非自適應；若顯著變差 → 自適應機制被證實。此實驗導讀未見，屬本頁提議（未驗證）。

## §8 · For the Reader

- **因子研究員**：可搬的是「輸入長度作為可學習門」這個想法，不必搬整個 MoE。最小可行改造＝在現有 patch 模型前加一層逆時序重要性 MLP，只做**加權池化**（把權重當 attention bias），驗證「動態窗口」是否真的比網格搜索的固定窗更好；先做單市場單模型對照，再談架構。
- **高頻執行／交易台**：注意這套東西只吐**次日個股預期收益**，最終倉位由凸優化器在行業中性、集中度、換手懲罰下解出——你的 alpha 上限被約束層再削一刀。评估時要求同一條流水線下跑「固定窗 vs 動態窗」的 A/B，否則實盤超額無法歸因。
- **組合配置**：導讀已自承單資產自適應看不到基差貼水與流動性踩踏，**不能把它當風控**。它適合當截面 alpha 的一路輸入，倉位層的 regime 硬約束必須另建。
- **LLM-agent／序列建模研究者**：逆時序累積＋嵌套前綴是一個乾淨的「變長上下文」歸納偏置，可遷移到長文檔／長對話的稀疏檢索；但要注意它的門檻是**全域固定**的，跨樣本的分位數校準（而非絕對閾值）可能才是可移植版本——此為推斷，未經驗證。
- **研究學生**：這是「質疑默認設定」型論文的範本——不改 backbone、不改 loss 主體，只把大家都不問的超參變成變量。讀它的正確方式是追問：**為什麼是累積而不是滑動窗口？為什麼是嵌套而不是互斥分段？** 這兩個「為什麼」就是可以拿去做 ablative 研究的題目。
